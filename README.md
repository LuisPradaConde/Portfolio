# Premium CV Portfolio

Base inicial para un CV/portfolio premium con:

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- next-intl
- Framer Motion

## Estructura

- `src/app`: rutas y layouts
- `src/components`: componentes reutilizables
- `src/data`: datos ficticios iniciales
- `src/i18n`: configuracion de idiomas
- `src/lib`: utilidades
- `messages`: traducciones por idioma
- `public`: archivos estaticos
